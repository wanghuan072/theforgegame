# The Forge Game — Wiki, Codes, Guides & Calculator

**Website:** [theforgegame.com](https://theforgegame.com/)

`theforgegame.com` is a fan-made hub for **The Forge (Roblox)**, built to help players find accurate, fast-to-use information: item databases, upgrade planning tools, redeem codes, and practical walkthroughs.

## What you’ll find here

- **Wiki database**: Browse weapons, armor, ores, pickaxes, enemies, locations, mechanics, NPCs, potions, quests, races, and runes.
- **Codes tracker**: A clean list of active/expired codes and how to redeem them.
- **Build & crafting calculator**: Plan upgrades, estimate costs, and compare options.
- **Guides**: Step-by-step walkthroughs for beginners and mid/late-game progression.
- **Tier lists**: Quick “what’s best” rankings with context and trade-offs.

## FAQ

### Is this the official website for The Forge?

No. `theforgegame.com` is an **independent fan site**. It is not affiliated with, endorsed by, or connected to The Forge or its developers. All trademarks belong to their respective owners.

### How often are codes updated?

The Codes page is maintained regularly. If a code stops working, it will be moved to the expired section as soon as possible.

### Where should I look first: Wiki, Guides, or Tier Lists?

- Use **Guides** if you want a step-by-step plan.
- Use the **Wiki** if you need exact stats, recipes, locations, or drop tables.
- Use **Tier Lists** if you want a fast recommendation (then verify details in the Wiki).

### I found incorrect info — how do I report it?

Please use the [Contact Us](https://theforgegame.com/contact-us) page with the page URL and what should be corrected.
